# yogesharma

Personal site built with Next.js (App Router), TypeScript, Tailwind CSS v4, MDX, and Shiki.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Writing

MDX posts live in `src/content/writings/`. Each post exports a `meta` object with `title`, `description`, and `date`.
